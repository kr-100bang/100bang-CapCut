# 100bang-CapCut
효율성 향상 도구 화면 캡쳐 스크린샷 툴 백방 캡컷

[ 백방 캡탑 (100bang CapTop) ]

백방 캡탑은 화면의 일부분을 빠르고 간편하게 캡쳐하여 항상 위에 떠있는 창(Floating Window)으로 띄워두는 강력한 생산성 도구입니다.
중요한 정보, 참조 문서, 디자인 시안 등을 화면에 고정시켜 작업 효율을 극대화하세요!

================================

[ 단축키 안내 (기본 설정) ]

프로그램 실행 중 설정 메뉴를 통해 단축키를 변경할 수 있습니다.

- 캡쳐 시작      : F1                    (스마트 스냅/방항키, 클릭 또는 드래그로 캡쳐)
- 이미지 저장    : F2                    (현재 선택된 캡쳐 이미지를 파일로 저장)
- 해당 창 닫기   : F3                    (현재 선택된(포커스된) 캡쳐 창을 닫음)
- 전체 창 닫기   : F4                    (화면에 떠있는 모든 캡쳐 창을 한 번에 닫음)
- 기능 ON/OFF  : Ctrl + Shift + F1    (캡쳐 기능을 잠시 비활성화/활성화)
- 프로그램 종료  : Ctrl + Shift + F2    (캡탑 프로그램을 완전히 종료)

================================

[ 사용 방법 ]

1. 프로그램 실행: 100bang_CapTop.exe를 실행합니다. (트레이 아이콘이 생성됩니다)
2. 캡쳐 모드 진입: F1 키를 누르면 화면이 어두워지며 캡쳐 모드가 시작됩니다.
3. 캡쳐 하기 (두 가지 방법):
    * 스마트 스냅 (Smart Snap): 창이나 버튼 등 UI 요소 위에 마우스를 올리면 "노란색 테두리"가 자동으로 감지됩니다. "마우스 왼쪽 클릭" 한 번으로 해당 영역을 즉시 깔끔하게 캡쳐합니다.
    * 자유 지정 (Drag): 원하는 영역을 "마우스 왼쪽 버튼으로 드래그"하여 직접 선택합니다.
4. 이미지 활용:
    * 자동 복사: 캡쳐된 이미지는 자동으로 클립보드에 복사됩니다. (Ctrl+V로 바로 붙여넣기 가능)
    * 항상 위 고정: 캡쳐된 이미지는 다른 창들보다 항상 위에 표시됩니다.
    * 이동/크기 조절: 이미지를 드래그하여 이동하거나, 가장자리를 잡아 크기를 조절할 수 있습니다.

================================

[ 주요 기능 및 팁 ]

1. 편리한 마우스 조작
    - 투명도 조절: 캡쳐 창 위에서 "마우스 휠"을 위/아래로 굴려 투명도를 조절할 수 있습니다. (뒤에 있는 내용을 봐야 할 때 유용함)
    - 컨텍스트 메뉴: 캡쳐 창 위에서 "마우스 우클릭"을 하면 메뉴가 나타납니다. (저장, 클립보드에 복사, 닫기)
    - 간편 버튼: 마우스를 이미지 위에 올리면 우측 상단에 "저장(💾)" 및 "닫기(❌)" 버튼이 나타납니다.

2. 설정 및 트레이
    - 트레이 아이콘: 작업 표시줄 우측 하단 트레이 아이콘을 우클릭하여 메뉴를 열 수 있습니다.
    - 설정: 단축키를 내 손에 맞게 변경할 수 있습니다.
    - 백방 블로그 바로가기: 도움말 및 업데이트 소식을 확인할 수 있습니다.
